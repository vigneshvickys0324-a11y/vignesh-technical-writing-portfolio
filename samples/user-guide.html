Getting Started with a Project Management Tool

A task-based guide to creating a project, assigning work, and tracking progress.

Audience: New users

Estimated reading time: 5 minutes

About this guide

This guide demonstrates a typical project management workflow using generic steps. The labels and features may differ from those in a specific product.

Before you begin

  • Make sure you can sign in to your organization's project management tool.
  • Confirm that you have permission to create projects and tasks.
  • Prepare a project name, a short description, and an initial task list.

Step 1: Create a project

  1. Open the projects area in the application.
  2. Select the option to create a new project.
  3. Enter a clear project name.
  4. Add a short description explaining the project's goal.
  5. Choose the appropriate visibility or access setting.
  6. Save the project.

Use a name that team members can recognize easily. Avoid including confidential information in a project title if it may be visible to a broad audience.

Step 2: Add a task

  1. Open the project you created.
  2. Select New task or the equivalent option.
  3. Enter a concise task title that describes the required outcome.
  4. Add the details, acceptance criteria, or supporting links.
  5. Set a due date if the project requires one.
  6. Save the task.

A good task description explains what needs to be done and how the team will know it is complete.

Step 3: Assign the task

  1. Open the task details.
  2. Choose the appropriate team member from the assignee field.
  3. Confirm the assignment.
  4. Check that the assignee has the information and access needed to complete the work.

Step 4: Update task status

Use the available status options to communicate progress. A common workflow might include:

  • To do: Work has not started.
  • In progress: Someone is actively working on it.
  • Blocked: Progress depends on resolving an issue.
  • Done: The task meets the agreed completion criteria.

Update status when circumstances change so other team members can rely on the project view.

Step 5: Review project progress

Open the project's overview or task list. Review overdue items, blocked work, upcoming deadlines, and tasks without an owner. Follow up with the relevant people when information is missing.

Troubleshooting

I cannot create a project. Check whether your account has the required permission. Contact your administrator if the option remains unavailable.

I cannot assign a task. Confirm that the intended person belongs to the workspace or project and is eligible to be assigned.

I cannot find a task. Clear restrictive filters, check the selected project, and search using a distinctive part of the task title.

Tip: Keep task titles specific, descriptions actionable, and status updates current. These habits make project information more useful for the entire team.

Summary

You have reviewed the basic workflow for creating a project, adding tasks, assigning work, updating status, and reviewing progress. Consult your actual product documentation for product-specific instructions and permissions.
